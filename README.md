# ENSAE Programming Project — Swap Puzzle

Course repository for the ENSAE first-year programming project on the **swap puzzle**.

The project represents puzzle states as grids and introduces graph-based methods for searching over possible states. The repository contains the course project structure, input instances and unit tests.

## Repository structure

- `swap_puzzle/` — Python classes for grids, graphs and solver logic;
- `tests/` — unit tests for the grid implementation;
- `input/` — puzzle instances used by the project.

## Python concepts

Object-oriented programming · graph representations · breadth-first search · testing · file I/O

## Status

This repository preserves coursework from the ENSAE programming project. Some starter-code methods remain intentionally incomplete, so it should be read as a course project rather than a finished software package.
